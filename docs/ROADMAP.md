### 6.5 — Distribution pipeline
> `cargo-dist` compiles the `pluq` binary per platform **and** generates the install front-ends. The `curl | sh` one-liner is the **hero path** (rustup / Claude-Code style): detects OS+arch, downloads the prebuilt binary, drops it on `PATH` → `pluq` works immediately. A compiled CLI *is* a binary; every method below delivers the **same** self-contained executable, no runtime required — that's the whole appeal.

- [ ] **`cargo-dist`** setup + GH Actions release workflow (compiles binaries + generates installers; also drives the launch release in 6.7).
- [ ] **One-liner install scripts** — `curl ... | sh` (unix/mac) + `irm ... | iex` PowerShell twin (Windows). The hero UX on every OS; both auto-generated by `cargo-dist`, both dodge Gatekeeper/SmartScreen (curl/irm don't set the quarantine / mark-of-the-web flag).
- [ ] GitHub Releases prebuilt binaries (mac x64/arm64, linux x64/arm64, windows x64) — the artifacts the install script downloads. Also the **fallback** for curl-averse / offline / CI-automation / Windows users. Not the recommended human path (manual place-on-`PATH`); just not hidden.
- [ ] Homebrew tap (`brew install`) — smoothest mac path (sidesteps Gatekeeper friction the install script can't).
- [ ] Scoop manifest (Windows) — optional.
